\# Snap\&Shop Setup Guide



\## 1. Overview



This document explains how to set up and run the Snap\&Shop project on a local development machine.



The project contains three main application areas:



\- Frontend

\- Backend

\- AI module



The project can support product recognition and comparison across online and offline/local store sources.



\---



\## 2. Prerequisites



Install the following software before setting up the project:



\- Git

\- Node.js

\- npm

\- Python

\- pip

\- Tesseract OCR



Verify the main tools with:



```text

git --version

node --version

npm --version

python --version

pip --version
